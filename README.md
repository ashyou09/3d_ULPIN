# 3D ULPIN - Vertical Cadastre System

An interactive 3D Cadastre visualization and land record management system for multi-level vertical property units (BKC model).

## Features
- **3D Vertical Cadastre Visualization**: Interactive 3D spatial modeling for multi-storey vertical parcels and volumetric land rights.
- **ULPIN Integration**: Support for 3D Unique Land Parcel Identification Numbers (ULPIN) tailored for vertical land records.
- **Layer & Zoning Controls**: Filter by zoning types (residential, commercial, utility, social, etc.) and ownership levels.
- **Cadastral Units & Ownership Matrix**: Detailed unit breakdown, floor-by-floor attributes, and compliance checks.
- **Light / Dark Mode**: Full theme customization with responsive typography and spatial UI.

## Usage
Simply open `index.html` or `bkc-vertical-cadastre.html` in any modern web browser.
